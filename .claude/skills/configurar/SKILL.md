name: configurar
description: Configura una bóveda de Obsidian desde este kit mediante preguntas simples, cuando el usuario pide empezar de cero o adaptar una bóveda existente. No usar para desarrollar el kit ni para retomar un proyecto ya configurado.
---

Leé primero `00_CORE/atoms/00_vault-rules.md` y después `00_CORE/protocols/configurar-vault.md`. Ese protocolo es la fuente única del recorrido de configuración.

Reutilizá las respuestas de esta conversación. Comprobá acceso y destino, preguntá lo que falta y prepará la bóveda vos mismo dentro del alcance acordado. No exijas comandos, YAML, selección de letras de contexto ni copia manual de plantillas. Si no hay acceso de escritura, seguí la alternativa del protocolo y explicá el límite antes de afirmar que configuraste algo.
