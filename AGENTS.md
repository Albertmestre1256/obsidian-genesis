# Instrucciones para asistentes

Este repositorio es un kit para iniciar bóvedas de Obsidian mediante una conversación.

Primero leé `00_CORE/atoms/00_vault-rules.md` y después `AI-INSTRUCTIONS.md`. Las reglas son compartidas; la guía distingue configuración inicial, trabajo diario y mantenimiento del kit.

Si el usuario pide empezar, configurar su bóveda o no sabe cómo usar la carpeta, seguí `00_CORE/protocols/configurar-vault.md`: preguntá en lenguaje simple y creá los archivos con sus respuestas. No le encargues editar YAML ni copiar plantillas si podés hacerlo vos.

Si ya hay una configuración vigente y el pedido es «quiero empezar» o «seguí», retomá el proyecto indicado o preguntá cuál quiere usar. No reinicies la entrevista. Una bóveda lista no implica que sus tareas estén terminadas.

Si pide desarrollar, revisar o corregir el kit, trabajá sobre ese pedido sin iniciar la entrevista ni personalizar los ejemplos. No supongas que el repositorio del kit es la bóveda personal del usuario.
