# Leer primero

Esta bóveda es una red de notas. Empezá por [[Panel|Mis proyectos]] para trabajar o abrí [[INDICE|Índice general]] para ver qué contiene.

La IA lee **[[INDICE|el índice completo]]**, después [[00_CORE/atoms/00_vault-rules|las reglas]] y el recorrido de [[AI-INSTRUCTIONS|la entrada para asistentes]]. Las reglas mandan sobre las notas; esta entrada no las sustituye.

Cada nodo general enlaza esta nota y el índice general. Los nodos hijos enlazan su padre y sus notas; las relaciones entre temas se añaden cuando el contenido las justifica. La IA mantiene esos enlaces cuando crea o amplía el contenido.

Para ver la red, abrí **Vista de gráfico** en Obsidian. Desde una nota o índice también podés abrir su **gráfico local**. [Ayuda del gráfico](DOCS/obsidian.md).

Si recién empezás, pedile a la IA que configure esta carpeta con preguntas simples. Podés omitir datos personales y completarlos después.
