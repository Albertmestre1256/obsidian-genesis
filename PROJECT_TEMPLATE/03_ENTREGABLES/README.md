# 03_ENTREGABLES — Resultados finales

Guardá acá las versiones que ya revisaste y aceptaste: un informe, una presentación, una carta, un plan terminado o cualquier resultado del proyecto. Pueden ser notas Markdown, documentos, PDFs u otros archivos.

Prepará y revisá primero el trabajo en [02_SINTESIS](../02_SINTESIS/). Comprobá su contenido, sus referencias y cualquier dato pendiente antes de tratarlo como final. El validador de fichas del kit no revisa la calidad ni la veracidad de un entregable.

Conservá las versiones finales: si hay una corrección, creá una nueva versión en lugar de sobrescribir la anterior. Por ejemplo, `plan-de-estudio_v1.md` y luego `plan-de-estudio_v2.md`.

Podés pedirle a la IA: «Prepará la versión final que revisamos y registrá cuál es la vigente». Guardar un archivo acá no significa que se haya enviado, publicado ni que todo el proyecto esté terminado.
