# 01_FUENTES — Material original

Guardá documentos, apuntes, datos o conversaciones recibidos para el proyecto. Conservá cada original tal como llegó: agregá archivos nuevos, sin editar los existentes. Para corregir o analizar una fuente, usá una copia o nota en [02_SINTESIS](../02_SINTESIS/).

Elegí nombres descriptivos. Puede quedar vacía hasta tener material.
