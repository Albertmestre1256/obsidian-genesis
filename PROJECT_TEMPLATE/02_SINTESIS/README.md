# 02_SINTESIS — Notas y borradores

Trabajá acá mientras una idea o un resultado todavía está en preparación: resúmenes, comparaciones, planes, notas de investigación y borradores de textos.

Estas notas pueden actualizarse. Antes de editar, la IA debe leer la versión actual y conservar tus cambios. Cuando uses información de una fuente, dejá un enlace o una referencia para poder encontrarla.

Podés pedirle: «Prepará un borrador con las fuentes de este proyecto y señalá lo que falta comprobar». Las propuestas y dudas deben distinguirse de los datos confirmados.

Un nombre como `plan-de-estudio.md` alcanza para empezar. Si necesitás conservar varias versiones, podés usar `informe_v1.md` y `informe_v2.md`.

Los originales se guardan en [01_FUENTES](../01_FUENTES/). Cuando revises y aceptes una versión final, guardala en [03_ENTREGABLES](../03_ENTREGABLES/). El objetivo y las próximas tareas se mantienen en la ficha del proyecto.
