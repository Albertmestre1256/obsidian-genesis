# 02_SINTESIS — Notas y borradores

Guardá resúmenes, planes y textos en preparación. Antes de editar, leé la versión actual y conservá cambios propios; enlazá las fuentes y distinguí datos, propuestas y dudas.

Conservá versiones cuando haga falta. Los originales van en [01_FUENTES](../01_FUENTES/); los resultados revisados y aceptados, en [03_ENTREGABLES](../03_ENTREGABLES/). Si agrupás notas en una colección, su índice local resume el contenido y la conecta al proyecto.
