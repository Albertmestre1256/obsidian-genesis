# Reglas Transversales del Vault (Átomo Fundamental)

> **Nivel:** Átomo — unidad indivisible de contexto. Se inyecta completa en cada sesión.

## Regla 1 — Comunicación
**Antes de producir CUALQUIER pieza comunicada, consultar `00_CORE/molecules/marco-comunicacion-general.md`.**
- Contexto A (técnico): evidencia verificable, precisión, cero exageración
- Contexto B (narrativo): historias verdaderas, coherencia, autenticidad
- Contexto C (persuasivo): storyline, beneficios, call to action
- Contexto D (operativo): claridad, intención, preguntar antes de asumir

## Regla 2 — Hecho vs Evidencia vs Interpretación
Distinguir siempre:
- **Hecho comprobable**: documento, certificado, código público
- **Competencia demostrada**: algo que se puede mostrar haciendo
- **Afirmación sin respaldo**: señalarla y proponer cómo conseguir evidencia

## Regla 3 — Separación de Niveles (Context Engineering)
- **Fuentes crudas** (`01_FUENTES/`) — no se interpretan, solo se agregan
- **Síntesis** (`02_SINTESIS/`) — trabajo activo, se actualiza seguido
- **Entregables** (`03_ENTREGABLES/`) — salida final, versionada

## Regla 4 — Contexto por Proyecto
Cada proyecto define su contexto dominante en su célula:
- Técnico → **A (evaluativo-técnico)**
- Narrativo → **B (evaluativo-narrativo)**
- Persuasivo → **C (persuasivo)**
- Operativo → **D (operativo)**

## Regla 5 — Inyección de Contexto
Al iniciar sesión: leer este átomo → leer célula del proyecto → aplicar reglas.
