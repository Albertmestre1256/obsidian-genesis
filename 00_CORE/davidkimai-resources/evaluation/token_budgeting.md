# Presupuesto de contexto

Un token es una unidad de texto usada por el modelo. El validador del kit estima el tamaño con cuatro caracteres por token; no es una medida exacta del modelo que estés usando.

Leé primero `INDICE.md` completo, después las reglas y la ficha del proyecto. Agregá fuentes o guías solo si hacen falta para la tarea, según `00_CORE/protocols/context-injection.md`. No omitas evidencia necesaria para cumplir un límite de tamaño.

No hay un presupuesto universal para retomar o redactar: depende del modelo y de la tarea. El validador del kit avisa cuando una ficha supera su estimación de 3000 tokens; no bloquea por tamaño ni obliga a borrar información.

Si la ficha crece, enlazá los detalles desde notas del proyecto. Para retirar contenido que dejó de estar vigente, proponé qué archivar y conservá el historial. Más información puede ser necesaria para un análisis; lo que conviene evitar es cargar material ajeno a la pregunta.
