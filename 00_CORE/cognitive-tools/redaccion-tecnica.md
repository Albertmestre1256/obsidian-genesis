# Redacción Técnica — Contexto A

## Principios
- Evidencia verificable > afirmaciones
- Precisión técnica > lenguaje florido
- Cero exageración, cero ambigüedad
- Métricas cuantificables obligatorias

## Estructura Estándar
1. **Resumen ejecutivo** (3-5 líneas, métricas clave)
2. **Contexto técnico** (stack, arquitectura, restricciones)
3. **Acción** (qué hiciste, herramientas, decisiones)
4. **Resultado medible** (métricas: % mejora, tiempo, $ ahorro)
5. **Lección técnica** (qué aprendiste, aplicable a futuro)

## Checklist Pre-Entrega
- [ ] Toda afirmación sale de un hecho de la sección **Hechos clave** de la célula (con fuente)
- [ ] Métricas cuantificadas (%, ms, $, GB)
- [ ] Stack técnico explícito (Python 3.11, pandas 2.1, etc.)
- [ ] Decisiones técnicas justificadas
- [ ] Cero adjetivos calificativos ("excelente", "robusto", "escalable")
