# Inicio rápido

1. Descargá y descomprimí el kit.
2. En Obsidian elegí **Abrir carpeta como bóveda** y seleccioná la carpeta que contiene `README.md`.
3. Abrí **Panel**. Adjuntá `00_CORE/atoms/00_vault-rules.md` y `00_CORE/cells/ejemplo-context.md` a tu IA y pedile resumir el proyecto ficticio aprender-python. Con Claude Code, abrilo en esa carpeta y usá `/empezar aprender-python`.

Después creá tu propio proyecto con `/nuevo-proyecto` o con los prompts de [Usar con otras IAs](usar-con-otras-ias.md).

**Bóveda existente:** desde la carpeta del kit, ejecutá `python instalar.py "ruta de tu bóveda"`. El instalador muestra conflictos y no reemplaza archivos. Para copia manual, seguí el [README](../README.md).

**Revisión opcional:** `python 00_CORE/schemas/validate.py`. No necesita paquetes adicionales. Sin Python podés pedir una revisión manual a la IA.
